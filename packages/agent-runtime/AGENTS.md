# Shared Runtime Agent harness

Runtime server and the Electron utility process are the two hosts. This package owns the portable primary SDK loop, instruction assembler, step policy, tool manifest/outcome, Bash definition, approval policy, portable tool registry and reusable Agent profiles. Shared defaults are definitions, not a global tool bag: resolve the exact profile before constructing `ToolLoopAgent`. Hosts inject model, sandbox, persistence and observation capabilities and append only host/agent/domain manifests; they must not enumerate shared defaults independently. Same-name additions replace a default logical slot, and profiles may disable defaults or opt into a narrow subset. Never import a service, database, Electron, credentials or host filesystem here. Keep SDK native approval, cancellation and UIMessage protocols. No parallel local tool protocol.

Keep source and public subpaths grouped by responsibility: `agent/` owns the loop and step/runtime control, `tools/` owns tool contracts, policy and implementations, `protocol/` owns UIMessage/artifact lifecycle, and `instructions/` owns prompt assembly. The package root exports only the primary Agent factory; other consumers use the owning grouped subpath. Internal source imports use the real module location. Do not restore flat compatibility aliases.

Run `just test shared/agent-runtime`, both host tests and builds, and root lint.

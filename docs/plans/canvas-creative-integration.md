# Canvas 用户端创作迁移

本批负责用户端 Studio、画布、故事板、分镜草稿、素材匹配、资源库及其公共 API。管控由独立 Agent 负责；`*_worker.go`、`archive_workflow.go`、内部 Worker 路由、Executor registry/公共 transport client、启动与部署仍由集成 Agent 负责。

## 已接通的创作闭环

- 分镜草稿支持剧本参数、持久化启动、渐进候选、刷新恢复、候选编辑 CAS、确认入图、取消和放弃。候选使用稳定身份与 revision，页面恢复后继续读取同一草稿。
- Studio 挂载源端结构的故事板：分镜编辑、固定视频预览、连续播放、生成历史、拖动排序、插入/删除分镜、首尾帧和参考素材编辑。`CanvasBoard.module.less` 与视觉资产沿用源端，仅将基础组件替换为 design-system。
- 项目素材搜索覆盖当前画布、其他画布生成产物与项目资源库。素材选择器也支持直接上传，完成后立即写入提示词引用或首尾帧槽位。选择外部素材时先物化到当前画布，再写入提示词 mention 和引用边；并发选用同一素材会在串行队列内再次检查，避免重复节点。
- 视频首尾帧支持处理状态读取、首帧/尾帧分别选用、物化为图片节点、替换及交换。处理中和失败状态在交互层显示明确错误。
- 智能素材匹配冻结节点 revision、提示词和候选集合，使用独立持久化运行记录，支持刷新恢复、取消、错误展示。模型结果在单次图事务内写入物化节点、引用边和提示词；匹配任务不会污染普通生成历史。
- 节点支持幂等复制并偏移位置，复制后自动选择新节点。图片、视频和音频产物可创建项目资产；资源 ID 在失败重试期间保持稳定。
- 画布视口按用户持久化，进入画布恢复，平移缩放结束后串行保存。
- 独立资源库恢复源端的信息层级：分类计数、搜索、本地文件批量建库、卡片预览、空态与错误态、素材管理弹层。素材管理包含上传、生成型插槽、生成配置与运行恢复、主素材、替换、历史版本、重命名、删除、送审和复制到画布。Studio 侧栏使用同一数据与操作，保留适合窄栏的紧凑布局。

## 设计与边界核对

- 正式图仍只来自 `store/graph.ts`；故事板、提示词素材条与节点面板不保存第二份正式图。
- 手动图修改继续经过 mutation coordinator；服务端 revision 与 operation ID 处理跨窗口并发，前端不自行递增 revision。
- UI 复用 `@repo/design-system`、lucide、源端 Less 和图像资产，没有引入 Arco 或旧物料包。
- 资源与画布之间复制的是独立内容 owner，资源删除不会破坏已经复制到画布的素材。对象物理回收与导出生命周期由集成 Agent 收口。
- Provider、任务执行和取消终态仍由 TS Executor/Workflow 与公共 Worker 接线负责；用户端只消费持久化状态，不模拟成功终态。

## 验证边界

已通过 Canvas TypeScript no-emit 类型检查、Canvas Oxlint/Oxfmt、Rspack 构建、Canvas Go 包检查以及 OpenAPI 同步后的契约检查。初始 PostgreSQL migration 已在隔离 schema 和回滚事务中执行通过。

尚未完成真实 Provider 的成功生成、运行中取消/重启恢复、完整资源生成及首尾帧提取成功链路验收。仓库规则指定页面交互由用户验证，本批没有启动浏览器或 GUI 自动化，因此不把静态检查与构建结果表述为视觉验收完成。
